WHAT: Patch 1 of the WF68K30L request handoff (F65). A completing prefetch long can roll S5 straight into S0 of the next prefetch long. Operand cycles are unchanged.
WHY: A real 68030 starts the next cycle on the edge after S5 when a request is pending. This core already does that between the halves of a sized long (31 ns). Between separate transfers it inserts IDLE and START_CYCLE (156 ns). This patch removes those two clocks for prefetch-to-prefetch only.
