WHAT: Adds the 68030 instruction cache in front of OPCODE_REQ. 16 lines of four long words, valid per word, tag A31:8 and FC2. CACR bit 0 enables it, bit 1 freezes allocation, bit 3 clears it. A data write drops the line. CPU space is not stored. A miss is the existing fetch. A hit does not start an ST cycle and returns the word with one OPCODE_RDY strobe. New file cpu030/wf68k30L_icache.vhd, wired in wf68k30L_top.vhd, added to build_tc138k.tcl and atarist_tc138k.gprj. Does not touch the diag overlay. Cable 417 only. Do not flash. Do not reflash TOS.
WHY: Every fetch still takes an ST cycle. This is the usable instruction cache, MC68030UM 6.1.1. Reset clears CACR bit 0, so the path is unchanged until software sets it. TOS 2.06 and EmuTOS do set it, so this must not be flashed until the build is accepted and David says so.
LOOK FOR: Build only. A pass is a bitstream, not a flash. The data cache is not in this patch. A hit that wedges the pipe is the failure mode; the bench has not been run.
